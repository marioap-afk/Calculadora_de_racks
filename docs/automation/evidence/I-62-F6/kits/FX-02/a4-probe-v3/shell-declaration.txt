Shell declarada: ejecuta cada comando con cmd.exe (la forma `cmd.exe /d /s /c "<comando>"` o la invocación equivalente de cmd.exe). No uses PowerShell, pwsh ni powershell.exe. No uses intérpretes (py, python, node u otros) ni las herramientas de Unix que el PATH pueda exponer (grep, sed, awk, find, wc, sort, head, tail, sha256sum, bash): solo órdenes internas de cmd.exe, git, y certutil, findstr y fc de %SystemRoot%\System32.
