5. Decisiones de arquitectura del Owner
Registra estas disposiciones:
Q-O1 — Piloto V1
Acepto provisionalmente una estación Cantilever de una sola cara como primer vertical slice.
La selección definitiva queda condicionada a que el modelo permita una transferencia estructural verificable y que no requiera introducir hipótesis incorrectas.

Acepto estudiar el uso de la base de datos de RAM Elements como fuente de propiedades estructurales del modelo analítico.
No autorizo todavía la asignación automática de grados de acero únicamente por familia geométrica.
