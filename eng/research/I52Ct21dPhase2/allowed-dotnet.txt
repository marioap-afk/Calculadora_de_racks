# Allowed .NET surface of the phase 2 production scripts (deny by default). Checked by tests/StaticScan.ps1 (layer B, AST).

# Every type literal, static member, instance member name (method OR property) and assigned member name that appears in
# lib/Phase2Common.ps1, Capture-Phase2.ps1 and Validate-Phase2.ps1 must be listed here, and nothing else may appear. The list was derived
# from the production scripts and then reviewed line by line against this rule: NOTHING on it starts a process, writes the registry,
# changes an ACL or an attribute, loads code or touches the network; the only write is Write, Flush and the create-new FileStream, and both are
# confined to the function Write-Phase2NewFile ("@Function" scope). Type keys are lower case with a leading "System." removed.
# Adding a line here is a change that needs the same review as a script change (this file is in HASHES-PHASE2.txt).
#
# Residual (stated in the README): member names are allowlisted by NAME, not per type. A listed name is allowed on every object.
# Dynamic member names, static calls on non-literals, string-typed -as/-is, $ExecutionContext, [type], [scriptblock] and
# reflection are not reachable because none of them is listed.
